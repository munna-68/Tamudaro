## Tanudaro — removed the mascot face from the timer ring

User brief: the mood face inside the ring (the "angry"/focus face and the
"active" one) was distracting — remove it and push.

### What shipped

- Deleted `src/components/Mascot.jsx` entirely (the SVG mood face: idle /
  focus / break / celebrate / sleep, plus its blink loop).

  derivation (`celebrate | focus | sleep | idle`) and the `<Mascot>` child.
- `src/components/BreakPanel.jsx` — same removal; `mood` there was only
  `celebrate | break`.
- `src/styles.css` — removed the now-dead `.ring-inner .mascot` rule.

`.ring-inner` is a centred flex column, so the clock + status pill simply
recentre with the face gone — no layout compensation was needed. The topbar
`🌀` is `brand__mascot` and was deliberately kept (it's not the face).

### Gotcha worth remembering

Editing several files in one parallel `Edit` batch silently half-applied here —
some edits landed, others were reported successful but were not on disk. Always
re-`grep`/re-read the files after a batch edit before building. Also: BSD grep
on macOS does **not** support `\|` alternation in BRE — a `grep "a\|b"` returns
no matches and looks like a false negative. Use `grep -E`.
